# Lexical access: two models

Reading notes for the psycholinguistics unit. The question of the week: when you hear an ambiguous word like bank, does context pick a meaning before the word is recognized, or only after?

## Model A: "Hear First, Filter Later" (Exhaustive Access / Late Selection)

- How it works: Activation moves strictly bottom-up (from sounds $\rightarrow$ words $\rightarrow$ meanings).
- The process:
- Your ears hear the sounds: b - æ - ŋ - k.
- Both entries in your mental dictionary—$\text{Bank}_1$ (money) and $\text{Bank}_2$ (river)—are equally and automatically activated, regardless of the sentence topic.
- All their meanings briefly flare up in your mind, including "land by water's edge."
- Only then does the context ("paycheck") step in as a judge to pick the correct meaning and discard the irrelevant one ($\text{X}$).
- Core idea: Language processing is strictly modular. The ear doesn't care about context; it boots up every possible meaning of the word first, and context selects the winner afterwards.

## Model B: "Expect First, Bias Early" (Interactive / Top-Down Pre-activation)

- How it works: Activation flows top-down as well as bottom-up.
- The process:
- Hearing "paycheck" immediately pre-activates financial concepts ("financial institution", "branches") before the word bank is even finished being spoken.
- Because those financial meanings are already warmed up, they send top-down activation straight to $\text{Bank}_1$.
- $\text{Bank}_2$ (river) is suppressed before it can compete: its activation never reaches threshold, $a_2 < \theta$.
- Core idea: The system is interactive. Context is not a judge that waits for the candidates; it is a thumb on the scale from the first sound.

## Evidence

Swinney (1979) used cross-modal priming: subjects heard a sentence biased toward one meaning and, right at the ambiguous word, saw a letter string on a screen. Both meanings primed at 0 ms (the probe right at the word), only the context-appropriate one at 700 ms. That is Model A's prediction: exhaustive access, then selection within about a second.

Later work with strongly biasing contexts and unequal meaning frequencies found cases where the dominant meaning primed alone even at 0 ms, which Model B predicts. The reordered access model splits the difference: frequency sets the order in which meanings become available, and context sets how long the search goes on, $t = f(\text{freq}, \text{context})$.

## Questions for the seminar

- If both meanings prime at 0 ms, why does the inappropriate one disappear so fast?
- Does the 700 ms window change with the strength of the context?
- How would each model explain a garden-path sentence?
