# Round 1: the answer beside a change names the change

One change: rule 9 of the action rules (lib/prompts/synthesis.ts). The answer to a message that asks for a change is one or two sentences that name what changes and where; nothing on the new words, what stays, the blocks left alone, the document's content, consequences, or advice; a confirmation gets one sentence. Sixteen cases on the lecture and meeting transcripts join the set (they have no round 0).

## What the answers show

The long-commentary fault class is gone: no judge in round 1 names consequences, other blocks' figures, or advice after a change. What the judges name now, each in several cases:

- The answer states the change as an offer ("I can make the first two headings h1") or says the message's words back, with the plan already attached (confirm-docs-narrow, confirm-news-decline, suggest-essay-shorten, suggest-essay-fix, suggest-zh-translate, edit-news-bold-term). Round 2 refines rule 9: a statement of what the plan does, never an offer, never the message echoed.
- An edit's answer names the old words but not the new (edit-memo-one-sentence, transcript-edit-words, the three lecture fixes). Round 2's rule 9 asks for both when a few words change.
- An answer to a question ends with an unasked aside: a mistake the reader might make, a derived figure, a second passage that neither answers nor contradicts, advice for the reader's purpose (answer-law-apply, answer-history-count, answer-zh-regulation, answer-essay-connection, answer-podcast-where, answer-news-followup). Round 2 adds rule 6 of the answer rules: stop at the answer.
- The edits a pass makes all carry the pass's one why as their description, so the plan card names no block and no words (edit-essay-formal, edit-essay-fix-mistakes, edit-docs-revise-whole). Fixed in code: an edit a pass made describes its own change (editDescription in lib/assistant/revise.ts), and the card's preview shows the window of the change (lib/assistant/diff-window.ts).
- A new document is still refused (section-podcast-document) or made as notes in new sections (section-notes-study-guide): no action made one. Round 2 ships create_document.

Single cases, hypotheses until a second shows: a transcript time written as the tag's raw seconds (answer-podcast-where, twice now across rounds: a rule candidate for round 3); a comment that repeats the paragraph's own sentences; a note sourced on the sentence next to the one it restates; a move that leaves a back-reference pointing at nothing; a document that cannot be changed answered with its reason and nothing it could do instead (scope-shared-import, twice now: a rule candidate for round 3).

## Weakest cases

### section-podcast-document (section) — overall 2
- Checks failed: actions block matches the ask (no actions block); expected actions proposed (type="create_document" text="Provenance"); documents made (no document made)
- Scores: right_shape 1, sourced 3, content 3, placement 1, answer 2, style 3, language 5
- Worst: right_shape — “None of my actions creates a document. / The plan: no actions.”
- Fix: Add create_document (title, text) to the actions the assistant's prompt lists, with the rule that a message asking for a new document yields one create_document action holding the title and one part per claim with its exact quote, and drop the rule that sends a new document to Stitch.

### section-notes-study-guide (section) — overall 2
- Checks failed: expected actions proposed (type="create_document" text="Calvin"); no stray action (add_note, add_note, add_note, add_note, add_note, add_note, add_note, add_note); documents made (no document made)
- Scores: right_shape 1, sourced 3, content 4, placement 1, answer 3, style 4, language 5
- Worst: right_shape — “Eight sections are added to the project, one note each”
- Fix: Add to the section rules: when the message asks for a document ('make a study guide document', 'a new document'), the plan is one create_document action whose text holds one part per heading, and add_note or a new section never stands in for it.

### scope-shared-import (scope) — overall 3
- Scores: says_where 5, no_actions 5, helpful 2, style 5, language 5
- Worst: helpful — “I cannot rewrite the first paragraph: a project of another account holds this document too, so its words cannot be changed. (nothing follows: no shorter paragraph in the answer, no offer of a note)”
- Fix: Add a prompt rule: when the document cannot be changed, follow the one sentence that says why with what the assistant can do instead, the asked-for text in the answer or an offer to save it as a note, never a bare refusal.

### section-memo-risk-notes (section) — overall 3
- Scores: right_shape 3, sourced 5, content 3, placement 5, answer 4, style 5, language 5
- Worst: right_shape — “with two notes, each quoting the memo: the volume risk from [block report-earnings-memo-b9] and the capacity risk from [block report-earnings-memo-b10] — no note on b7, 'The fuel part will not repeat ... next quarter's margin loses about 1 point from fuel alone.'”
- Fix: Add a rule: when the message says one note per X the document names, list every block that states an X across the whole document before writing the plan, not only the blocks under the heading X, and write one note per listed block (here b7, the fuel reversal, is missing).

### suggest-essay-reorder (suggest) — overall 3
- Scores: one_action 5, scope 5, instruction 3, reorder 5, answer 4, style 3, language 5
- Worst: instruction — “Use two to four groups.”
- Fix: Add a rule: when reorder is true, the instruction lists each group in order, its heading and the block ids it holds, instead of leaving the number of groups or their members to the edit pass.

### edit-essay-formal (edit) — overall 3
- Scores: right_action 3, exact 4, minimal 3, answer 3, descriptions 2, style 4, language 5
- Worst: descriptions — “The reader asked for a formal essay with no first person, no contractions, and every number kept.”
- Fix: Add a prompt rule that each edit_block description quotes the words the action removes and the words it puts in (for b2: replace "I will take it last" with "this essay addresses it last"), never a restatement of the reader's request.

### answer-memo-margin (answer) — overall 4
- Scores: answer_first 5, evidence 4, complete 5, honest 5, fit 5, no_actions 5, style 5, language 5
- Worst: evidence — “"Of the 2.8-point rise in operating margin, about 1.1 points is **structural** and should hold, and about 1.7 points is **fuel** and is already reversing [block report-earnings-memo-b12]" cites b12, which says 1.1 and 1.7 but not 2.8 (that is in b6); and "(9.1 less 1 point)" cites no block, 9.1 is in b3.”
- Fix: Add a rule: every number in a sentence must appear in a block cited in that same sentence, so the 2.8 cites [block report-earnings-memo-b6] and the 9.1 cites [block report-earnings-memo-b3].

### answer-docs-limits-count (answer) — overall 4
- Scores: answer_first 5, evidence 4, complete 3, honest 5, fit 5, no_actions 5, style 5, language 5
- Worst: complete — “"**Three** separate limits apply to each key [block docs-rate-limiting-b12]": the cited block goes on to say "An account can hold up to 20 keys" and "A key's bucket size can be raised to 6,000 requests on request", and the answer names neither the key cap nor the raise, both terms a lawyer counting limits needs.”
- Fix: Add a rule: when the reader asks how many limits there are, name every cap and every term that changes a cap in the blocks read, so b12's 20-key cap and the 6,000 bucket raise are counted or named as left out and why.

### answer-news-followup (answer) — overall 4
- Scores: answer_first 5, evidence 4, complete 5, honest 5, fit 3, no_actions 5, style 5, language 5
- Worst: fit — “"At the press conference she also said: \"Core prices are still rising faster than we can accept...\" [block news-rate-decision-b3]. Core inflation, which leaves out food and energy, has stayed at 3.6 percent for three months against a 2 percent target [block news-rate-decision-b2]." and "For your loan, that means she did not rule out a cut. One economist says a December cut depends on the **September inflation reading**... [block news-rate-decision-b8]. If the bank cuts, lenders expect the 30-year fixed rate to fall from 6.9 toward 6.5 percent by December": the question asked for her answer to the dissenters, which b6 gives in the first paragraph; the other two paragraphs are context the reader did not ask for, where one sentence on the December cut would do.”
- Fix: Add a rule for a follow-up in a conversation: answer from the blocks that answer the question, then at most one sentence for the reader's purpose, and cite no block the question did not ask about.

### answer-law-apply (answer) — overall 4
- Scores: answer_first 5, evidence 5, complete 5, honest 5, fit 3, no_actions 5, style 4, language 5
- Worst: fit — “The likely slip is to count from 7 March, when the acceptance reaches Alder, as the general rule that an acceptance must be communicated would suggest”
- Fix: Add a rule: never add a paragraph on the mistake the reader might make or on a reading the document does not take; answer the question asked and stop.

### answer-zh-regulation (answer) — overall 4
- Scores: answer_first 5, evidence 5, complete 5, honest 5, fit 5, no_actions 5, style 4, language 5
- Worst: style — “对你的决定，关键是你的店属于哪一类。”
- Fix: Add a rule: a tie to the reader's Purpose is at most one sentence and brings in no block or number the question did not ask for.

### answer-essay-connection (answer) — overall 4
- Scores: answer_first 5, evidence 5, complete 5, honest 5, fit 5, no_actions 5, style 4, language 5
- Worst: style — “For scale, the author's first slow read of a paper took eleven hours”
- Fix: Add a rule: cite a second passage only when it answers the question or contradicts the first; drop asides on time, cost, or scale the reader did not ask about.
