## Decisions

- Tab with no toolbox open in a paragraph gives a first-line indent, the text's own Tab there, never a tab character over selected words.
- The assistant's box keeps the textarea of Viewing's box (rows 2, Enter sends), so the box is one shape in every mode.
- At 1000 px, with no room beside the page and the page unable to move, the box takes the toolbox's rest width (176 px) beside the page rather than going under the words.
- The fold order uses `break` in the comeback: a group comes back only after every group folded after it.
- The comment thread is kept in memory for the page's life, not in the browser's storage: it is the server's data, refreshed on every open.
- PAGE16-05: a time gate (400 ms, under Android's 500 ms long press) rather than opening Search the menus on pointerdown, because the menu covered the button; the gate removes the cause.
- PAGE16-12: only the per-key drawing was cut; `readSuggestions` is already cached per document, and in Suggesting every key changes the suggestion, so reading only "when the marks change" would not skip anything.
- PAGE16-07: the page's slide was left alone; it comes from the margin and `docsShift` race in `reader-interactions.tsx` (shared, many call sites), and the column sliding is on the "not this round" list.
- My test data stays for the verifier: project "Fix r16 page" (cmv0mtx7f00007d32s7yx2w8x), its documents (BLANK cmv0mu6p100027d32tq5pzzgk, BLANK2 cmv0mub0o001x7d32ql8xl5se, TABLE cmv0mudtl003s7d32l2g84cs4, BLANK3 cmv0mula3004n7d32wqsfzo6i, BLANK4 cmv0mulrj006i7d32nt0ivsde, PDF import cmv0r243m000d7d78h3b7newe), section "Fix notes" (cmv0qad2h00017dggkgxqcp5e) with a note and a reply (cmv0wb72k00017dikcfzkm4id). All made through the app; delete each document with `DELETE /api/documents/:id`, then the project, when the round closes. The typed test words were removed from every document (checked in the database).
